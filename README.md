## Sobre o Projeto

O sistema foi desenvolvido para auxiliar a ONG na divulgação de ações sociais, captação de voluntários e fortalecimento da presença digital da instituição.

Atualmente, a associação realiza divulgações principalmente pelas redes sociais pessoais da responsável. O projeto busca centralizar essas informações em uma plataforma própria, organizada e acessível.

## Funcionalidades

* Página institucional
* Área de notícias e campanhas
* Sistema de cadastro de voluntários
* Painel administrativo
* Galeria de imagens
* Layout responsivo
