\\# ❤️ PIESC — Associação Doe Amor e Gere Esperança







Projeto desenvolvido para o \\\*\\\*Projeto de Extensão (PIESC)\\\*\\\* do curso de \\\*\\\*Análise e Desenvolvimento de Sistemas — Uningá\\\*\\\*.







O objetivo do projeto é desenvolver um site para auxiliar a \\\*\\\*Associação Doe Amor e Gere Esperança\\\*\\\*, de Astorga - PR, na divulgação de suas ações sociais, projetos e oportunidades de voluntariado.







A proposta é facilitar o acesso às informações da associação e fortalecer sua presença no meio digital.







\\---







\\## 📌 Sobre o projeto







A Associação Doe Amor e Gere Esperança realiza ações voltadas ao apoio e à solidariedade, contando com a participação de voluntários e da comunidade.







Atualmente, grande parte da divulgação das ações é realizada por meio das redes sociais pessoais da responsável pela instituição.







Pensando nisso, o projeto busca criar uma plataforma própria para centralizar essas informações e facilitar a comunicação com pessoas interessadas em conhecer, participar ou apoiar as ações da associação.







\\---







\\## 🎯 Objetivos







\\\* Divulgar as ações realizadas pela associação;



\\\* Facilitar o contato com a instituição;



\\\* Incentivar novas pessoas a participarem como voluntárias;



\\\* Fortalecer a presença digital da associação;



\\\* Centralizar informações importantes em um único local;



\\\* Facilitar o acesso da comunidade às ações e projetos sociais.

\\## 🖥️ Executando o projeto localmente







Para executar o projeto em um computador utilizando o XAMPP:







\\### 1. Instale o XAMPP







O projeto utiliza o \\\*\\\*Apache\\\*\\\* para executar as páginas PHP.







\\### 2. Coloque o projeto na pasta `htdocs`







Exemplo:







```text



C:\\\\xampp\\\\htdocs\\\\Piesc-dage-site



```







\\### 3. Inicie o Apache







Abra o painel do XAMPP e inicie o serviço:







```text



Apache



```







\\### 4. Acesse pelo navegador







Depois de iniciar o Apache, abra:







```text



http://localhost/Piesc-dage-site/



```
